# 🚀 Rpmalloc 源码硬核剖析与多核并发图解 (教学版)

本项目是针对高并发内存分配器 `rpmalloc` 的底层物理级剖析与并发图解教程。

---

## 📂 仓库目录导读

* 📁 **1. 代码**：包含中文深度注释、重新整理过的核心运行代码。
* 📁 **2. 图解**：
  * `01.图解_基础篇.png`：主攻多线程隔离、Heap/Span/Page 基础堆栈拓扑。
  * `02.图解_进阶篇.png`：主攻无锁队列 Mailbox 物理防 ABA 逻辑、128字节对齐感知分辨率的终极位运算推导。
* 📁 **3. 学习过程**：记录了从零到一攻坚底座和位运算逻辑的心路历程。
* 📊 **简单测试_性能对比.png**：多线程并发压力下，rpmalloc 与常规分配器的吞吐性能物理实测。
